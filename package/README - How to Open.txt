Computer Storage Cleaner - Linux v1.1

How to open:
1. Double-click: Open Slow Computer Rescue
2. If Linux asks, choose Run or Run as Program.

Inside the app:
1. Leave the cleanup boxes checked unless you want to skip something.
2. Click Check and Clean My Computer.
3. Review the preview.
4. Click Clean Selected Items.
5. Confirm cleanup.

Tip: Close Chrome/Firefox/Brave first if you want more browser cache cleaned.
