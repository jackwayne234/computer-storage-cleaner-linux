# Computer Storage Cleaner for Linux

A simple Linux cleanup helper for people whose computer feels slow or cluttered.

Watch a short demo of this app:

## Download

Download the latest ZIP from the **Releases** section of this GitHub repository.

- Platform: **Linux**
- Current release: **v1.1**

## Who it is for

Everyday Linux users who want a simpler way to review cleanup options without digging through terminal commands.

## What it does

- Beginner-friendly desktop interface
- Helps review common storage cleanup areas
- Designed for local use on the computer
- Avoids terminal-first cleanup workflows

## Privacy / safety notes

- Local desktop utility
- Designed for user review before cleanup
- No cloud account required

## How to open

1. Download the ZIP from **Releases**.
2. Extract/unzip it.
3. Open the included README or launcher file inside the extracted folder.

Some Linux systems require right-clicking the launcher and choosing **Run as Program**.
